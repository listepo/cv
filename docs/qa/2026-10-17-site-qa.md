# listepo.dev QA, 2026-10-17

Live site tested with headless Chrome at 360, 390 and 1440 px, plus a code review of `main`.
Console errors and failed requests: none. All internal links return 200.
The only non-200 external link is LinkedIn (HTTP 999, bot blocking, not a bug).

## Bugs

### 1. Horizontal scroll at 360 px: project cards and contact rows overflow (fixed)

- **Severity:** medium
- **Steps:** open https://listepo.dev/ at a 360 px viewport and scroll to Projects.
- **Expected:** page width equals the viewport (360).
- **Actual:** `scrollWidth` is 368. The four featured cards are 8 px too wide, because the
  `white-space: nowrap` command line (`.project__cmd`) widens the `1fr` grid track. The contact
  rows have the same flaw at 320 px.
- **Fix:** use `minmax(0, 1fr)` tracks in `.featured` and `.contact`, and `min-width: 0` on
  `.project` and `.contact__val`.

### 2. No security headers on listepo.dev (not fixed here, hosting config)

- **Severity:** low
- **Steps:** `curl -I https://listepo.dev/`.
- **Expected:** `Strict-Transport-Security`, `X-Content-Type-Options`, `Referrer-Policy`, and a
  CSP.
- **Actual:** none of them are sent. The site is behind Cloudflare, so they belong in a
  Cloudflare Transform Rule or a `_headers` file, not in the repo's nginx.conf.
- **Suggested fix:** add the headers at the Cloudflare layer.

### 3. Duplicate hosts: www.listepo.dev serves the site, no redirect (not fixed, hosting)

- **Severity:** low
- **Steps:** `curl -sI https://www.listepo.dev/`.
- **Expected:** 301 to the canonical host.
- **Actual:** 200, a duplicate of the apex.
- **Suggested fix:** add a Cloudflare redirect rule.

### 4. No sitemap, and no `Sitemap:` line in robots.txt (not fixed)

- **Severity:** low
- **Actual:** `/sitemap-index.xml` and `/sitemap.xml` return 404.
- **Suggested fix:** for a one-page site this is optional; add `@astrojs/sitemap` if wanted.

### 5. Live deploy differs from `main` (informational)

- **Severity:** info
- **Actual:** the live HTML uses a `/cv/` base (`/cv/_astro/...`, canonical
  `https://listepo.dev/cv/`), but `main` defaults to the domain root (`site.config.mjs`).
  The live build may be stale or built with `SITE_BASE=/cv`. Confirm which one is intended.

### 6. External GitHub link tap target below 24 px (not fixed)

- **Severity:** low
- **Actual:** the `https://github.com/pyrlyn` link in the page body measures under 24 px high
  at all widths.
- **Suggested fix:** add `min-height` and padding to inline `.link` anchors.
